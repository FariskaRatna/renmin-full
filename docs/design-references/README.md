# Referensi desain (hanya untuk prinsip)

Analisis design system milik produk lain, diambil dari VoltAgent/awesome-design-md (MIT).
Dipilih yang relevan dengan aplikasi kerja internal yang padat data:

- `linear.app.md` — aplikasi produktivitas yang padat tapi tenang, hierarki tipografi kuat.
- `notion.md` — konten panjang, tata letak dokumen, kesan ringan.
- `ibm.md` — gaya enterprise (Carbon): grid ketat, tabel dan form yang serius.
- `sap.md` — aplikasi bisnis (Fiori): pola form, tabel, dan alur persetujuan.
- `airtable.md` — tampilan data/tabel yang ramah.

ATURAN: identitas SIERA DELTA LIMA tetap mengikuti `docs/UIUX-DESIGN-SYSTEM.md`
(navy + gold, warna per unit, token di `apps/frontend/src/style.css`).
Ambil prinsipnya (kepadatan, ritme spasi, perlakuan tabel, hierarki teks), JANGAN menyalin
palet, font, logo, atau ciri khas merek mana pun. Baca file di sini hanya bila diminta
atau saat merumuskan arah redesign, bukan di setiap tugas.
