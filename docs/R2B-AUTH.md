# Siera Delta Lima — R2B Authentication Implementation

**Status:** Patch prepared; Mac Docker and end-to-end OTP verification pending.

## Components

- Go/chi: `/api/v1/auth/{csrf,bootstrap-status,login,verify-otp,me,logout}`.
- Argon2id PHC password hashing: t=3 / m=64 MiB / p=2; 16-byte random salt.
- 6-digit OTP from CSPRNG. HMAC-SHA256 of `(challenge, OTP)` persists in DB, never raw code.
- Challenge expiry 5 minutes, maximum five code attempts, single use and prior pending challenge invalidation.
- SMTP over TLS 465 or STARTTLS 587, authenticated, TLS certificate verification required; no bypass.
- Session: 32-byte random opaque token, only SHA256 digest in PostgreSQL, 8-hour fixed lifetime, revocable on logout.
- Browser: SameSite=Strict HttpOnly session cookie; CSRF double-submit token plus mandatory trusted Origin for mutating routes.
- Password rate-limiting persisted to PostgreSQL (hashed account and peer IP), temporary lock after five failures.
- Administrative audit events without passwords/OTP/session tokens.
- Bootstrap: guarded one-time command from stdin; no fixed credentials or password argv/environment.
- **Development only:** `SDL_COOKIE_SECURE=false` for `http://127.0.0.1:5174`. HTTPS Secure-cookie enforcement is mandatory for production.

## Usage on Mac (do not share `.env`, SMTP credentials, OTP, or passwords)

1. Install R2B patch via packaged installer; run `./sdl-run.sh`. This regenerates Go checksums if needed and validates Go/React builds.
2. Run `bash ./scripts/bootstrap-superadmin.sh` to create the first account. The email must be one you can receive.
3. Configure in project `.env` with your own valid SMTP account:

   ```ini
   SDL_SMTP_HOST=smtp.example.internal
   SDL_SMTP_PORT=587
   SDL_SMTP_USER=replace-locally
   SDL_SMTP_PASSWORD=replace-locally
   SDL_SMTP_FROM=replace-locally@example.internal
   ```

   Supported ports: 465 implicit TLS or 587 STARTTLS. Keep `.env` permission `600`. `SDL_AUTH_SECRET` is generated by installer; **never replace it**, or existing challenge HMAC validation will fail. Passwords containing reserved Compose `.env` characters must follow Docker Compose's `.env` quoting/escaping rules.
4. Restart services using `./sdl-run.sh` to apply SMTP settings; go to `http://127.0.0.1:5174`, login and verify OTP email. Do not send SMTP credentials to ChatGPT.

## Explicit limitations / next milestones

- The React portal is a **visual preview only** after authentication; business module CRUD remains disabled.
- R2C must add backend permission checks to every protected business endpoint and unit-scoped data access.
- Production deployment needs HTTPS reverse proxy, trusted origin configuration, cookies with `Secure`, secret management, log policy, backups and independent security testing.
- This patch has no destructive migrations, no database reset, and does not overwrite previous R2A SQL.
